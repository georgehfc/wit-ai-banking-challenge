# design/

Specs that both Figma work and code read from.

- `DESIGN.md`: principles, experience model, layout, components, motion (Google DESIGN.md format; values are placeholders)
- `tokens/tokens.json`: DTCG 2025.10 tokens, mirrors Figma variables
- `TONE.md`: voice, rules, patterns, microcopy
- `ASSISTANT.md`: roles, lanes, states, widget catalog, journey script, guardrails
- `ACCESSIBILITY.md`: WCAG 2.2 AA plus chat- and chart-specific rules
- `SECURITY.md`: trust commitments and where each shows
