# AI log

## Tool stack

- **Figma MCP (fundamental piece).** The bridge between AI and the design file: Claude creates and edits the Figma file through it (pages, scaffolding, reference board, later variables, component docs and the handoff/Code Connect mapping). Whatever solution we land on goes through it; every use is logged below.
- **Claude (claude.ai) and Claude Code: core tools.** Research and verification with sources, mock data and the deterministic planner, design specs (DESIGN.md, tokens, tone, assistant, accessibility, security), copy drafts, checks and critique. Claude Code is where George picks up build work (backlog in `plan/04`).
- **Mobbin MCP**: benchmark search.
- **Claude in Chrome**: the network bridge for moving Mobbin images into Figma.
- Process lessons: `ai-log/learnings.md`.
