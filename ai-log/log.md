- **Figma MCP (fundamental piece).** The bridge between AI and the design file: Claude creates and edits the Figma file through it (pages, scaffolding, reference board, later variables, component docs and the handoff/Code Connect mapping). - **Claude in Chrome**: the network bridge for moving Mobbin images into Figma.
